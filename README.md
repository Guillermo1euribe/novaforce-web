Sitio multipágina orientado a la presentación de PCs preensambladas. Combina una portada visual, un catálogo organizado por gamas y secciones de contenido con una estética oscura.

## Qué incluye

- Portada con carrusel de imágenes y accesos al catálogo.
- Catálogo dividido en gama baja, media, alta y extrema.
- Tarjetas con especificaciones, precios referenciales y enlaces de consulta.
- Páginas de nosotros, contacto, blog y noticias.
- Componentes de Bootstrap: navegación, pestañas y tooltips.

## Tecnologías

HTML, CSS, Bootstrap 5.3.7 y Bootstrap Icons 1.11.3. Incluye JavaScript de Bootstrap y una inicialización de tooltips en el catálogo.

## Ver el proyecto en tu equipo

```bash
git clone https://github.com/pavoneh/novaforce-web.git
cd novaforce-web
```

Abre `index.html` en tu navegador o utiliza Live Server desde Visual Studio Code. No requiere instalación de paquetes ni proceso de compilación. Mantén la conexión a internet para cargar los recursos externos.

## Archivos principales

| Ruta | Contenido |
| --- | --- |
| `index.html` | Portada y presentación |
| `tienda.html` | Catálogo por gamas |
| `nosotros.html` | Presentación de Nova Force |
| `contacto.html` | Página de contacto |
| `blog.html`, `noticias.html` | Contenido editorial |
| `estilos.css` | Identidad visual y estilos propios |

## Estado actual

Es una vitrina frontend estática: los productos se definen en HTML y los botones de consulta llevan a la página de contacto. No incluye carrito, procesamiento de pagos ni gestión de inventario. Bootstrap, sus iconos y las imágenes externas requieren conexión a internet.
